# Minarbot Strategy

## Vision

<!-- vision: author-approved 2026-11-27 -->

`Minarbot` exists so that one person can hand real work to a team of AI agents and get it done, on their own machines, without depending on any single agent product.
It serves its owner first, and the people the owner invites.
It owns exactly one thing: the workspace where agents live and work - agents, projects, context, computers, schedules and machines - while the thinking comes from the harnesses it plugs in.

### Agents that finish the job

An agent takes a short request and carries it through to a checked result, without the owner stepping in.
Each agent has its own always-on computer, so it can use a browser, files and programs the way a person would.
Work also starts without the owner: on a schedule, or from events in the tools the owner already uses.
An agent checks its own work before it calls a task done.
Minarbot is judged by how many real tasks its agents finish, not by how many features it has.

### Agents start from zero and grow

Every agent starts clean, with Minarbot's built-in abilities and what the owner gives it, nothing else.
The owner's personal CLI setup never leaks into an agent, so an agent behaves the same on every machine.
An agent gets better from its own work: what it learns becomes memory and skills the owner approves.
This is what makes a Minarbot agent more than the coding CLI underneath it.

### One workspace across the owner's machines

Agents, projects and context follow the owner across every machine they control, and agents work together across them.
The desktop and mobile apps are the main way in; chat apps such as WhatsApp or Telegram are optional doors.
Setup happens in place and the interface explains itself through familiar patterns, not hint text.

### The owner chooses the brains

Codex, Claude Code and other agent engines plug in as they are, so their updates arrive without a fork.
The owner chooses which engines and models run, and when Minarbot updates.
Code search, memory and the computer are Minarbot's own and always on, with nothing to configure.
Other products, T3 Code among them, are references to learn from; Minarbot does not copy their code or follow their roadmap.

### Shared by invitation

Others join only when the owner invites them.
An invited person can read the context the owner shares, and works with their own agents from their own device or with the owner's agents.
There is no public signup, no billing and no paid tier; Minarbot is free and open source.

### Scope

Minarbot is not an AI model, a model router or an agent engine of its own.
It is not a coding IDE and not a copy of any other product.
It is not a messaging bot; chat apps are doors into the agents, not the product.
It is not a public hosted service.

A change aligns when it lets agents finish more real work on their own, makes the workspace easier to use every day from the desktop or mobile app, or lets the owner choose an engine, a model or an update without giving up anything.
A change should be resisted when it ties Minarbot to one agent product, hands agents the owner's personal setup, copies another product's code or roadmap, adds configuration for something that should just work, or opens Minarbot to the public.
