# Agents and conversations

Open **New agent** from the workspace menu. Give the agent a name, instructions, and a model. Choose **Run with** to select its connection. Open the agent from the sidebar to send it a message. Use **New conversation** for a separate thread.

In an agent's sidebar menu, **Edit** changes its profile, **Hide** removes it from the main list, and **Restore** brings it back from Hidden agents. Use **Export template** from the conversation menu to save a profile. Use **Import template** in the workspace menu to create another agent from that file.

Starter templates for onboarding:

- Researcher: find primary sources, cite claims, and flag gaps. Return a brief with links and open questions.
- Project coordinator: summarize progress, decisions, and blockers. Ask before assigning owners or changing deadlines.
- Writing assistant: draft for the requested audience and channel. Preserve facts and flag missing details.

Adapt each starter's instructions to the user's work. Ask for their goal and desired output before proposing a profile.
