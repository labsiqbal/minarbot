# Routines

Open [[routines]] and choose **New routine**. Select an owner agent, enter the task, and choose a trigger. Use a schedule for time-based runs, Manual for on-demand runs, or Webhook for signed requests. Choose where the report should appear. Open a saved routine to edit it or see its runs.

# Workflows

Open [[workflows]] to create a workflow. Pick an owner agent, add and connect steps, and save. Open a saved workflow to run it and inspect the result.

# Projects

Open the **Projects** sidebar tab and choose **New project**. Add folders and agents, then use sections and conversations to organize work.
