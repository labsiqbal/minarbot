# AI connections

Open [[settings.providers]] to add an API provider. Enter its endpoint, key, and default model in the form. Open [[settings.engines]] to check engine availability or set up a separate engine login. Codex and Claude Code can also use their existing sign-in on the machine. Choose an available connection with **Run with**, then select the model.

# Connected apps

Open [[settings.connected-apps]] to set up Composio, choose an app, and sign in to it. Grant access per agent after connecting. Finish sign-in in the browser. Enter keys in Settings. For an MCP server, use [[settings.mcp]] to test and save the connection, then grant the agent specific tools.
