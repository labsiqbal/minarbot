# AI connections

Open [[settings.providers]] and choose **Add provider** to add Codex, Claude Code or an ACP engine. Each provider keeps its own sign-in, executable, launch arguments and encrypted environment variables. Codex and Claude Code sign in with a ChatGPT or Claude account. In an agent, choose the **Provider**, then a **Model** and its options.

# Connected apps

Open [[settings.connected-apps]] to set up Composio, choose an app, and sign in to it. Grant access per agent after connecting. Finish sign-in in the browser. Enter keys in Settings. For an MCP server, use [[settings.mcp]] to test and save the connection, then grant the agent specific tools.
